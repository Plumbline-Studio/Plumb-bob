PLAYSCRIPT: Lantern Order
Purpose: A visitor browses the Lantern Supply Co. catalog, orders a
Lantern Classic, and reaches a confirmation that honestly summarizes the
order. Working means the money path completes and the flow stays honest:
no hidden charges, no manufactured pressure.

 1. User    Opens the catalog page.
 2. System  Shows two products with prices (Lantern Classic $29.00, Lantern Pro $49.00).
 3. User    Opens the order page for the Lantern Classic.
 4. System  Shows an order form with name and quantity fields and a Place Order button.
 5. User    Fills in name and quantity and submits the order.
 6. System  Shows a confirmation immediately after submission, summarizing item, quantity, and total.
 7. User    Clicks Done to return to the catalog.
 8. System  (Integrity veto) Verifies the order flow **never adds a charge the user did not explicitly choose**.
